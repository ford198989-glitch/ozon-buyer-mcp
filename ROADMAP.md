# Price Hunter MCP — дорожная карта развития

**Обновлено:** 13 октября 2026 г.  
**Текущая версия:** 0.6.2.  
**Статус:** план разработки, **не** перечень уже реализованных функций.

## Цель

Находить **наиболее выгодное надёжное предложение**, а не просто минимальную цену в поисковой выдаче: одинаковая модель и комплектация, реальное наличие, понятное состояние и гарантия, итоговая стоимость с доставкой, проверяемый продавец. Результаты должны быть воспроизводимыми и снабжёнными ссылками и уровнем уверенности.

## Исходная архитектура и ограничения

- Текущая продуктивная схема: **ChatGPT → защищённый HTTPS MCP → Linux/Acer relay → native worker → локальный Chrome CDP**. Старые Railway/Windows-сценарии в README исторические.
- Уже подключены Ozon, Wildberries, Яндекс.Маркет, Мегамаркет, Avito и общий поиск интернет-магазинов; доступность и полнота данных каждого источника варьируются.
- MCP остаётся **read-only**. Не автоматизировать покупки, оплату, вход в аккаунты и обход CAPTCHA. Токены, cookie и другие секреты никогда не выводить в результаты или логи.
- Новый функционал должен сохранять контракты `market_search`, `market_compare`, `best_buy` либо вводить версионированные поля/новые инструменты.

## P0 — исправить выбор предложения до расширения каталога

1. **Точная идентификация товара.** Выделять бренд, артикул производителя (MPN), EAN/GTIN при наличии, ревизию, объём, интерфейс, комплектность, цвет/вариант. Нормализовать регистр, тире и пробелы, **но не** смешивать, например, IronWolf `ST2000VN003` и `ST2000VN004`. Для явно указанного артикула несовпадения **отклонять**, а не понижать порог relevance. Результат «точной модели нет» допустим.
2. **Качество данных.** Хранить признаки `exact_model_match`, `seller`, `condition` (new/refurbished/used/unknown), `warranty_months`, `stock_status`, `retrieved_at`, `source`, `price_confidence`. Отсутствие данных обозначать `unknown`, не выдумывать «новый» только по названию магазина.
3. **Безопасный best_buy.** Считать основным победителем только предложение с подтверждённым артикулом, положительной доступностью и достаточно проверенными ценой/состоянием. Подозрительные, refurbished, без ясной гарантии и Avito показывать **отдельно**. Убрать fallback, при котором слабое совпадение или низкая уверенность становится «лучшей покупкой».
4. **Реальная полная цена.** По возможности учитывать доставку, обязательные комиссии, минимальную сумму заказа, купоны и зависимость от способа оплаты. Явно показывать `base_price`, `shipping`, `total_price`; если итоговая цена неизвестна, помечать её оценочной.
5. **Проверка карточки.** Перед рекомендацией открывать конкретную товарную страницу; проверять, что артикул, цена, продавец и состояние совпадают с выдачей, а не с соседней вариацией товара. Отдельно отмечать возможные восстановленные HDD и необходимость SMART/серийной проверки после получения.

### Регрессионный пример для P0

Запрос «Seagate IronWolf 2 ТБ ST2000VN003» **не должен** объявлять победителем дешёвый `ST2000VN004`. Сборка «Synology DS223j + 1/2 NAS-HDD 2 ТБ» должна содержать совместимые компоненты и цену выбранного количества дисков, с раздельными вариантами минимальной и проверенной цены.

### Правила добавления каждого магазина

- Проверить доступность сайта и извлекаемость карточек из штатного браузера без обхода блокировок.
- Подключать как отдельный адаптер с идентификатором источника и диагностикой `ok / empty / blocked / failed / stale`; не выдавать отсутствие выдачи за отсутствие товара.
- Возвращать унифицированные поля товара, продавца, наличия, артикула, цены, доставки, гарантии и ссылки. Невозможные к подтверждению поля = `null`.
- Сохранять частичные результаты при сбое одного сайта; ограничить таймауты, объём открываемых страниц и частоту запросов.
- Дедуплицировать одинаковые предложения разных доменов, продавцов и торговых групп; отображать канонический источник и альтернативы.

## P2 — реальная экономическая эффективность и аналитика

1. **Честный бенчмарк MCP против независимого веб-поиска:** фиксированные товары и конфигурации, одинаковая дата, регион, количество, состояние и условия оплаты. Метрики: лучшая **подтверждённая** итоговая цена, доля точных совпадений, доля ссылок с живой карточкой, покрытие магазинов, доля с понятной гарантией, время ответа.
2. **Отчёт об экономии:** абсолютные ₽ и %, база сравнения и число реально проверенных предложений. Не объявлять «самое дешёвое в интернете» при неполном покрытии. Разделять `cheapest_found` и `best_verified_value`.
3. **Профили покупок:** электроника/NAS, СКУД/ОПС/электротехника, инструменты, автотовары, домашняя техника. Фильтры по новым товарам, CMR/SMR (для HDD), гарантии, минимальной цене, сроку доставки и региону.
4. **Мониторинг качества:** source-health по последним проверкам, частота CAPTCHA/блокировок, неверных совпадений, процент уточнённых карточек, перцентиль времени ответа; без персональных токенов/данных и без бесконтрольного автоматического скрейпинга.

## Очерёдность для Codex и критерии готовности

- **Этап 1 — P0 / тесты.** Набор минимум из 20 товарных запросов (включая схожие артикулы HDD, варианты ёмкости, восстановленные товары и ложные скидки). Ноль ложных победителей с отличающимся явным MPN; при неполных данных результат честно помечен как неподтверждённый.
- **Этап 2 — P1 / пилот.** Сначала **DNS + Ситилинк + Регард**, затем ОнлайнТрейд, М.Видео/Эльдорадо, XCOM, НИКС, Холодильник.ру, потом инженерные магазины. Для каждого — успешный запрос, проверка карточки, обработка отсутствия товара, блокировки, несовпадения региона и цены.
- **Этап 3 — P2 / измерение профита.** Прогнать не менее 20 одинаковых поисковых сценариев через MCP и независимый поиск; зафиксировать подтверждённую экономию и время без выдачи неподтверждённых цифр за факты.
- Код/фикстуры/тесты документировать в GitHub. Переход к внедрению на Linux/Acer — только после тестов и проверки read-only/OAuth. Само добавление этого файла **не развёртывает** новые адаптеры.

## Практический тест-кейс: семейный NAS

Сравнить `Synology DS223j`, один `Seagate IronWolf ST2000VN003 2 ТБ` и `WD Red Plus WD20EFPX 2 ТБ` с 1 диском на старте, далее с 2 дисками. Раздельно показывать лучшую цену, доказательства новизны, гарантию и итог за комплект. `ST2000VN004` не подменяет `ST2000VN003`. Обновлять результаты по реальным карточкам и не рекомендовать сомнительные диски для семейного фотоархива без оговорок.
